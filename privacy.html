Privacy Policy

Last updated: October 17, 2026

Application

rclone Drive Jofre is a personal configuration of the open-source rclone software for accessing Google Drive.

Google User Data

The application requests Google Drive access to allow its owner to list, read, upload, modify, synchronize, and delete files.

Data Storage

OAuth credentials are stored locally on the owner's computer. The application does not operate a separate server for collecting Google Drive data.

Data Sharing

The application does not sell or share Google Drive data with third parties.

Data Retention

Files remain under the owner's control. Local authentication credentials can be removed by deleting the rclone configuration.

Access Revocation

Google account access can be revoked through Google Account security settings.
